# AI-Powered Resume Intelligence and Job Matching System

## Project Overview
An AI-powered web application that analyzes resumes and compares them with job descriptions to identify skill matches, missing skills, keywords, and improvement suggestions.

## Features
- Upload resumes in PDF and DOCX formats.
- Extract resume text automatically.
- Calculate an ATS-style keyword match score.
- Identify matched and missing skills.
- Detect missing keywords.
- Generate resume improvement suggestions.

## Technologies Used

### Backend

- FastAPI
- PyMuPDF
- python-docx
